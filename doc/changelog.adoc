== Changelog

What changed in crypto in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#crypto-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added crypto, C-backed primitives setting DIT on arm64 macOS, iOS, Linux and Android: ciphers, curves, randomness, self-wiping secret<N>, errors 1 to 20, `+[[nodiscard]]+` results, WEBCPP_CRYPTO_HAS_THREADS, asynchronous functions on Asio.
* Added constant_time_equal, random_device, pem on libsodium, the AES block cipher ciphers::aes128, aes192 and aes256 with a per-target default, and ciphers::gcm, aes128_gcm and aes256_gcm: incremental seal, two-pass open, failures zeroing data.
* Added supports_v with its family tags, the capability table per target, default_backend_t and /webcpp/crypto//<family>-default per family and target (secp256k1's modules among them), and refusals naming their Jamfile line.
* Added backends::bearssl (AES-GCM, ChaCha20-Poly1305, curves::p256: keys, low-S ECDSA, agree, SPKI/PKCS#8; allocating nothing), backends::openssl natively and on WASI (allocating at from_key only, or in openssl_memory_resource with WEBCPP_CRYPTO_OPENSSL_MEMORY_RESOURCE), and backends::ctaes.
* Added curves::secp256k1: key pairs signing with crypto::ecdsa_sha256 (hedged too), ecdsa_sha256_recoverable and schnorr, agree in three forms, strict DER, low-S, tweaks, SPKI, PKCS#8, PEM, ElligatorSwift, MuSig2, silent payments.
* Added curves::ed25519 and curves::x25519 on libsodium: strict verification (twelve edge cases), Ed25519ph as crypto::eddsa_prehashed and the streaming prehashed_signer over hash's sha2_512, the conversion, all-zero agreements refused, RFC 8410's SPKI, PKCS#8.
* Added backends::sodium on /third_party//sodium, shared with webcpp::hash, every backend's link-time canary and C suite, and ciphers::basic_chacha20_poly1305: chacha20_poly1305 (also BearSSL, OpenSSL), the original form, xchacha20_poly1305, failed seals and opens zeroing data.
* Added secret_key_encryption's secretbox and secretbox_xchacha20poly1305 without associated data, public_key_encryption's box, box_xchacha20poly1305 and sealed_box, key_exchange::kx_keypair on libsodium, on typed X25519 keys.
* Added the page: chapters per namespace and use case, the memory option's guide, generated tables, Jamfiles, messages, llms.txt, release-built sizes and throughput, X25519 timing findings (wasip2, DIT).
* Added signing.hpp, keypair.hpp, factories.hpp, secret_key_encryption/aead.hpp, erase_secret.hpp: typed signatures, sign(scheme, input), verify; keypair, signing_keypair, agreement_keypair; aead::cipher, authenticated_box; from_secret, from_bytes, from_key.
// end::unreleased[]
