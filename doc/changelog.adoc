== Changelog

What changed in crypto in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#crypto-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added crypto: authenticated encryption, randomness and secp256k1 over C backends.
* Added the errors of crypto, with fixed values, in the category webcpp.crypto.
* Added equal, a constant-time comparison of tags and Boost.Hash2 digests.
* Added /webcpp/crypto//openssl, which links the superproject's OpenSSL 3.5.9 on native, wasip2 and wasip3, and refuses Emscripten with the line to write.
* Added the default backend, and the refusals of a build whose backends cannot work together.
* Added aes128, aes192 and aes256, the AES block cipher on a backend that exports it.
* Added gcm, AES-GCM in place: seal and open, every guard before any byte is read, and a failed open's data zeroed.
* Added gcm's incremental seal, begin_seal, update and result, whose every error ends the message.
* Added random_device, which reads the system's or the browser's generator and nothing else.
* Added the link-time canary of the backend BearSSL, and BearSSL's own test suite on webcpp's build.
* Added backends::openssl, AES and AES-GCM on OpenSSL 3.5.9, on native, wasip2 and wasip3.
* Added aes128_gcm and aes256_gcm on the default backend, and <webcpp/crypto.hpp> includes the header of each backend the build links.
* Added the backend ctaes, the AES block cipher alone on every target: `aes128/192/256<backends::ctaes>`; `gcm` on it is refused with the backends that have one.
* Added the pages on the block cipher, the backends and the user's Jamfiles.
// end::unreleased[]
