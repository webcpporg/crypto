[#crypto-gcm]
== AES-GCM

`gcm<Cipher>`, in the namespace `webcpp::crypto::ciphers`
(`<webcpp/crypto/ciphers/gcm.hpp>`), is AES-GCM (NIST SP 800-38D) with the key
size of `Cipher`, on the backend of `Cipher`, which must export GCM over its own
AES: BearSSL or OpenSSL; `aes128_gcm` and `aes256_gcm`
(`<webcpp/crypto/ciphers/aes256_gcm.hpp>`) name it on the default backend. It is
made with `make(key)` and works in place: `seal` encrypts a message and gives
its tag, `open` checks the tag and decrypts. Every guard runs before any byte
is read, and a failed `open` zeroes the data it was given. A message can also
be sealed in pieces, with `begin_seal`, `update` and `result`; any error ends
the message. On ctaes, which has no GCM, `gcm` does not compile
(<<crypto-block-gcm>>).
