= crypto: authenticated encryption, randomness and secp256k1 for {cpp}
:toc: left
:toclevels: 1
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn

crypto gives a {cpp}20 program the cryptography that Boost does not provide, on
every target webcpp has, one of the libraries of
https://github.com/webcpporg/webcpp[webcpp]. The algorithms are those of C
libraries, BearSSL, OpenSSL, ctaes and libsecp256k1, each a backend that the
program names in its own Jamfile.

This page teaches crypto concept by concept. The <<reference,reference>> that
closes it lists every name the headers declare.

== Reference

Every name crypto declares, in the namespaces `webcpp::crypto` and its
`backends`, from the Doc Comments of its headers: each class, function, type
and enumerator with its declaration, what it does, what it asks of its caller
and how it fails. The other sections teach the library; this one is where a
name is looked up.
