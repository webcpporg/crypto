== Changelog

What changed in crypto in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#crypto-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added crypto, C-backed primitives setting DIT on arm64 macOS, iOS, Linux and Android: ciphers, curves, randomness, self-wiping secret<N>, errors 1 to 20, `+[[nodiscard]]+` results, WEBCPP_CRYPTO_HAS_THREADS, asynchronous functions on Asio.
* Added equal, random_device, pem on libsodium, the AES block cipher ciphers::aes128, aes192 and aes256 with a per-target default, and ciphers::gcm, aes128_gcm and aes256_gcm: incremental seal, two-pass open, failures zeroing data.
* Added supports_v with its family tags, the capability table per target, default_backend_t and /webcpp/crypto//<family>-default per family and target (secp256k1's modules among them), and refusals naming their Jamfile line.
* Added backends::bearssl (AES-GCM, ChaCha20-Poly1305, curves::p256: keys, low-S ECDSA, agree, SPKI/PKCS#8; allocating nothing), backends::openssl natively and on WASI (allocating at make only, or in openssl_memory_resource with WEBCPP_CRYPTO_OPENSSL_MEMORY_RESOURCE), and backends::ctaes.
* Added curves::secp256k1: key pairs signing with crypto::ecdsa_sha256 (hedged too), ecdsa_sha256_recoverable and schnorr, agree in three forms, strict DER, low-S, tweaks, SPKI, PKCS#8, ElligatorSwift, MuSig2, silent payments.
* Added curves::ed25519 and curves::x25519 on libsodium: strict verification over twelve edge cases, Ed25519ph over hash's sha2_512 (/webcpp/crypto//crypto brings hash), the conversion, agree refusing all-zero secrets, RFC 8410's SPKI and PKCS#8.
* Added backends::sodium on /third_party//sodium, shared with webcpp::hash, every backend's link-time canary and C suite, and ciphers::aead: chacha20_poly1305 (also BearSSL, OpenSSL), the original form, xchacha20_poly1305, failed seals and opens zeroing data.
* Added ciphers::secretbox and secretbox_xchacha20poly1305, without additional data, hybrid::box, box_xchacha20poly1305 and sealed_box (failed seals and opens zeroing data), and curves::x25519::kx_keypair (crypto_kx) on libsodium, refusing peer keys of small order.
* Added the page: chapters per namespace and use case, the memory option's guide, generated tables, Jamfiles, messages, llms.txt, release-built sizes and throughput, X25519 timing findings (wasip2, DIT).
* Added signing.hpp and keypair.hpp: sign(scheme, input) and crypto::verify(scheme, signature, input, key), synchronous and asynchronous, a digest only as crypto::prehashed; every key pair's typed public key, secret(), agree.
// end::unreleased[]
