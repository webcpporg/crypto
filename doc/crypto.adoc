= crypto: cryptographic primitives for {cpp}
:toc: left
:toclevels: 2
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn

crypto gives a {cpp}20 program the cryptographic primitives that Boost does not
provide, on every target webcpp has: native (Linux, macOS, Windows with MSVC),
wasip2, wasip3 and Emscripten. It is one of the libraries of
https://github.com/webcpporg/webcpp[webcpp]. The algorithms are those of
widely used, reviewed C libraries, BearSSL, OpenSSL, ctaes, libsecp256k1 and
libsodium, each a backend that the program names in its own Jamfile.

The page is written for two readers at once: a developer who knows little
cryptography, and a language model that must pick the right tool for a
person's application from this page alone. <<crypto-choose>> answers "what do
I use for ..." in one table; each chapter opens with a table that compares
what it holds; every program shown is an example of the library's `example`
directory, built and run on every target with the output printed beside it.
The same content, as a machine-readable index, is link:llms.txt[`llms.txt`],
beside this page.

== Reference

Every name crypto declares, in the namespaces `webcpp::crypto`, `backends`,
`ciphers`, `curves` and `hybrid`, from the Doc Comments of its headers: each
class, function, type and enumerator with its declaration, what it does, what
it asks of its caller and how it fails. The other sections teach the library;
this one is where a name is looked up.
