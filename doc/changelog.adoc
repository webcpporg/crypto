== Changelog

What changed in crypto in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#crypto-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added crypto, primitives over C backends: ciphers, curves and randomness, errors of fixed values in webcpp.crypto, every result `+[[nodiscard]]+`, and WEBCPP_CRYPTO_HAS_THREADS, defined natively and with Emscripten's -pthread unless WEBCPP_CRYPTO_NO_THREADS is.
* Added equal, random_device, ciphers::aes128, aes192 and aes256, the AES block cipher, and ciphers::gcm, AES-GCM in place with an incremental seal whose failed open zeroes the data.
* Added default_backend_t and /webcpp/crypto//<family>-default, one default backend per family and target whatever is linked, ciphers::aes128_gcm and aes256_gcm, and refusals naming the Jamfile line and another backend's type.
* Added backends::bearssl (AES-GCM alone, allocating nothing), backends::openssl via /webcpp/crypto//openssl natively and on WASI (allocating at make only, or natively in openssl_memory_resource with WEBCPP_CRYPTO_OPENSSL_MEMORY_RESOURCE), and backends::ctaes (block cipher alone).
* Added curves::secp256k1: key pairs, BIP340 and ECDSA signatures, ECDH, strict DER, low-S and the x-only tweak.
* Added curves::ed25519 and curves::x25519 on libsodium: strict verification tabled on twelve edge cases, Ed25519ph over webcpp::hash's sha2_512 (/webcpp/crypto//crypto brings hash), the conversion, and agree refusing all-zero secrets.
* Added backends::sodium on /third_party//sodium, shared with webcpp::hash, every backend's link-time canary and C suite, and ciphers::aead, refusing other families first: chacha20_poly1305 (also BearSSL, OpenSSL), its original form and xchacha20_poly1305.
* Added the page: a chapter per namespace and use case, the memory option's guide and example, tables generated from the tests, every Jamfile and message, and llms.txt.
* Added supports_v, the capability table on the target being compiled, and the tags of its families and algorithms, which ciphers::gcm, the AES block cipher and secp256k1's key pair name.
* Added secret<N>, a self-wiping array that is copied only by clone, and the errors 13 to 20: memory_functions_refused, memory_functions_not_installed, weak_public_key, invalid_point, invalid_scalar, invalid_padding, invalid_encoding and invalid_ciphertext_size.
// end::unreleased[]
