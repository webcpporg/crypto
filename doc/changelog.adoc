== Changelog

What changed in crypto in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#crypto-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added crypto, primitives over C backends: ciphers, curves and randomness, with errors of fixed values in webcpp.crypto, every result `+[[nodiscard]]+`, and WEBCPP_CRYPTO_HAS_THREADS, defined natively and on Emscripten with -pthread unless WEBCPP_CRYPTO_NO_THREADS is.
* Added equal, random_device, ciphers::aes128, aes192 and aes256, the AES block cipher, and ciphers::gcm, AES-GCM in place with an incremental seal whose failed open zeroes the data.
* Added default_backend_t and /webcpp/crypto//<family>-default, one default backend per family and target whatever is linked, ciphers::aes128_gcm and aes256_gcm, and refusals naming the Jamfile line and another backend's type.
* Added backends::bearssl (AES-GCM allocating nothing, no block cipher), backends::openssl through /webcpp/crypto//openssl on native and WASI (allocating at make only), and backends::ctaes (block cipher alone).
* Added WEBCPP_CRYPTO_OPENSSL_MEMORY_RESOURCE: OpenSSL's allocations in the program's resource, refused on WebAssembly (WASI included) and without OpenSSL: openssl_memory_resource, install_memory_functions, memory_functions_refused, memory_functions_not_installed.
* Added curves::secp256k1: key pairs, BIP340 and ECDSA signatures, ECDH, strict DER, low-S and the x-only tweak; curves::ed25519 on libsodium: key pairs, signatures verified strictly (each backend's verdicts on the twelve edge cases of "Taming the many EdDSAs" tested and tabled), the X25519 secret key and public key, and Ed25519ph over webcpp::hash's sha2_512, which /webcpp/crypto//crypto now brings; and curves::x25519 on libsodium, whose agree refuses an all-zero secret.
* Added backends::sodium on /third_party//sodium, shared with webcpp::hash and initialised before every engine, and every backend's link-time canary and C suite.
* Added the page: a chapter per namespace and use case, the memory option's guide and example, tables generated from the tests, every Jamfile and message, and llms.txt.
* Added supports_v, the capability table on the target being compiled, and the tags of its families and algorithms, which ciphers::gcm, the AES block cipher and secp256k1's key pair name.
* Added secret<N>, a self-wiping array that is copied only by clone, and the errors 15 to 20: weak_public_key, invalid_point, invalid_scalar, invalid_padding, invalid_encoding and invalid_ciphertext_size.
// end::unreleased[]
